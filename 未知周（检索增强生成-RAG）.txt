# 第二周课程清单：检索增强生成（RAG）基础落地
## 本周核心目标
基于第一周的多轮对话框架，从零搭建一套可本地运行的 RAG 问答系统，掌握 RAG 全链路原理与工程实现，最终实现「基于本地私有文档的智能问答」能力，所有代码按工程规范迭代合并入主分支。

---

## 模块一：RAG 核心原理与全链路架构
### 核心知识点
1. RAG 解决的核心痛点：大模型知识截止、幻觉问题、私有数据/内部文档无法直接使用
2. RAG 核心思想：「检索外部知识 + 拼接进提示词 + 大模型基于知识生成答案」
3. RAG 标准全链路 7 个环节：文档加载 → 文本切片 → 向量化 → 向量存储 → 语义检索 → 结果重排 → 上下文拼接生成
4. 选型对比：RAG vs 大模型微调的区别、适用场景与成本差异
5. 工业界 RAG 的典型架构分层：数据层、检索层、应用层

### 实操任务
- 绘制 RAG 全链路数据流图，明确每个环节的输入与输出
- 确定本周技术栈：本地轻量方案，不依赖云服务

### 产出物
- RAG 架构认知与技术选型确认

---

## 模块二：文档处理与文本切片（数据预处理层）
### 核心知识点
1. 常见文档格式加载：纯文本、Markdown、PDF 等格式的读取方案
2. 文本切片的核心原则：语义完整性、检索召回率、生成准确性的平衡
3. 主流切片策略对比：固定长度切片、语义切片、按文档结构切片
4. 关键参数设计：切片长度、切片重叠率的取值逻辑与影响

### 实操任务
1. 实现通用文档加载器，支持本地 txt/md 文件读取
2. 实现「固定长度+重叠区间」的切片函数，可配置参数
3. 测试不同切片大小对文本完整性的影响

### 产出物
- `document_processor.py` 独立模块：文档加载 + 文本切片能力

---

## 模块三：向量嵌入与向量数据库（存储检索层）
### 核心知识点
1. Embedding 向量的本质：文本语义的数值化表示
2. 嵌入模型选型：开源轻量模型 vs 商用接口的对比
3. 向量数据库的核心作用：相似度检索、向量增删改查、海量数据索引
4. 本地轻量向量库选型：FAISS 与 Chroma 的适用场景

### 实操任务
1. 接入开源 Embedding 模型，实现文本转向量
2. 接入 FAISS 本地向量库，实现向量的批量写入与持久化
3. 实现基础语义检索：输入查询文本，返回 Top N 最相似的文本片段

### 产出物
- `vector_store.py` 独立模块：向量存储 + 语义检索能力

---

## 模块四：检索增强与对话框架集成（应用层）
### 核心知识点
1. 检索策略：基础相似度检索 vs MMR（最大边际相关性）检索的区别
2. 检索结果重排：提升召回精度的核心手段
3. RAG 专用 Prompt 工程：上下文拼接模板、答案约束指令
4. 和第一周多轮对话框架的集成方式：无侵入式增强原有对话能力

### 实操任务
1. 编写 RAG 专属系统提示词，规范模型基于检索内容作答
2. 实现检索结果的拼接与注入，和原有对话历史兼容
3. 将 RAG 模块完整集成进第一周的多轮对话客户端
4. 验证效果：导入测试文档，测试问答准确性与幻觉抑制效果

### 产出物
- 完整可运行的 RAG 对话系统：支持基于本地文档问答
- 复用第一周的上下文截断、异常捕获、多轮对话能力

---

## 模块五：基础调优与工程化收尾
### 核心知识点
1. RAG 效果常见问题：检索不召回、答案幻觉、上下文无关
2. 基础优化方向：切片参数调整、检索数量调整、提示词优化
3. RAG 基础评估方法：问答准确率、召回率、事实一致性

### 实操任务
1. 调优切片大小、重叠率、检索条数等核心参数
2. 用测试文档验证问答效果，定位并修复典型问题
3. 按工程规范整理代码，模块解耦、注释完善
4. 走标准开发流程：功能分支提交 → PR 发起 → 审核合并 → 打版本标签

### 产出物
- `v0.2.0` 稳定版本归档
- 主分支合并完成，保留完整提交历史与版本快照

---

## 前置说明
1. **和第一周的关系**：完全基于第一周的多轮对话框架增量开发，原有对话逻辑、Token 截断、异常处理全部复用，不破坏已有功能
2. **运行成本**：全程采用本地开源组件，无需调用付费向量服务，仅保留原有的大模型调用成本
3. **难度梯度**：从原理到组件再到集成，循序渐进，最终交付可复用的工程化模块
