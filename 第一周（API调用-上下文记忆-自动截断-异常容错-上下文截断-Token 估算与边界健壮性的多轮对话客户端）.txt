# 第一周 具体课程安排

**总目标**：掌握 AI PoC 必备的 Python 最小语法子集，打通大模型 API 调用，最终产出一个带上下文记忆、自动截断、异常容错的可运行多轮对话客户端。
**总耗时**：约 8~10 小时，拆分为 7 个独立课时，可分散在一周内完成。

---


## 课时 1：环境搭建与 Python 基础入门

**时长**：约 1.5 小时

- 核心知识点
  1. Python 3.11 安装、pip 包管理、虚拟环境创建与激活
  2. JupyterLab 启动与基础使用、代码块运行
  3. Git 仓库创建、基础提交命令
  4. 变量、print 输出、注释、基本数据类型
- 实操任务
  1. 搭建项目虚拟环境，安装`openai`、`python-dotenv`依赖
  2. 创建 GitHub 仓库，编写 README 初稿，提交 Hello World 脚本
- 验收标准：能在 JupyterLab 独立运行代码块，完成代码提交

## 课时 2：核心数据结构：列表与字典

**时长**：约 1.5 小时

- 核心知识点
  1. 列表：增 (append)、删 (pop)、改、查、下标规则
  2. 字典：键值对操作、嵌套结构
  3. 「列表嵌套字典」对应 LLM 对话消息格式
- 实操任务
  1. 手动构造符合 OpenAI 规范的 messages 消息列表
  2. 完成消息的追加、按位置删除、内容修改练习
- 验收标准：能独立写出 system/user/assistant 三种角色的消息结构

## 课时 3：流程控制：循环与条件判断

**时长**：约 1 小时

- 核心知识点
  1. `if-else`条件判断、相等 / 空值判断
  2. `while True`无限循环、`break`退出循环
  3. `input()`用户输入交互
- 实操任务
  1. 实现最简循环对话：反复接收输入并回显，输入`quit`正常退出
- 验收标准：循环可正常退出，无语法报错

## 课时 4：函数封装与接口异常处理

**时长**：约 1.5 小时

- 核心知识点
  1. `def`函数定义、参数、返回值
  2. `try-except`异常捕获机制
  3. 大模型 API 调用参数规范
- 实操任务
  1. 封装`llm_chat()`单轮对话函数
  2. 接入火山方舟 OpenAI 兼容接口
  3. 捕获网络超时、限流、参数错误三类异常
- 验收标准：调用函数可正常返回回复，异常场景程序不崩溃

## 课时 5：多轮对话与上下文管理

**时长**：约 1.5 小时

- 核心知识点
  1. 变量的生命周期：循环内 / 外的区别
  2. 历史消息的追加逻辑与持久化
  3. 多轮对话的消息交替规则
- 实操任务
  1. 将单轮对话改造为多轮对话
  2. `history`初始化放在循环外，每轮追加 user 和 assistant 消息
- 验收标准：连续对话模型可记住上文，历史消息完整累加

## 课时 6：上下文截断与边界健壮性

**时长**：约 1.5 小时

- 核心知识点
  1. `pop()`删除后下标自动偏移机制
  2. 滑动窗口截断原理
  3. Python 缩进语法规则、函数定义顺序
  4. 空值 / 空白内容校验
- 实操任务
  1. 实现`trim_history()`按对话轮数自动截断
  2. 增加模型空返回校验，避免脏数据写入历史
  3. 修复缩进、函数定义顺序等常见 bug
- 验收标准：对话超轮数自动删除最早记录，空返回不污染历史

## 课时 7：Token 估算与第一周整合验收

**时长**：约 1 小时

- 核心知识点
  1. 中文 token 简易估算方法
  2. 按 token 截断对比按轮数截断的优劣
  3. 全场景联调与自测
- 实操任务
  1. 实现`estimate_token()`简易估算函数
  2. 整合全部代码，完成全边界场景自测
  3. 完整代码提交 GitHub
- 验收标准：程序可稳定连续对话，具备自动截断、异常容错能力
